## How to rerun

From the repository root, with gmsh and getdp from apt and scikit-fem in `/home/claude/fea/venv`:

```
tests/independent/m6/fea/run.sh or11    # 2 min 5 s here
tests/independent/m6/fea/run.sh or12    # 44 s here
```

`run.sh` builds `tests/independent/m6/fea/.venv` from `/home/claude/release_0.0.1/embodic-0.0.1-py3-none-any.whl` if
it is missing (override with `EMBODIC_WHEEL`, `WHEEL_VENV`, `FEA_PYTHON`). It recomputes embodic's values first, then
meshes, solves and post-processes every run of the case. It writes `results/tool_versions.txt` (wheel sha256 f114a6e7...
dcd0, gmsh 4.12.1, GetDP 3.2.0, scikit-fem 12.0.2), `results/embodic_reference.json`, and per case a JSON and a Markdown
table file. Each run directory keeps its `.geo`, `.pro` and `solver_log.txt`. The meshes are not committed. The `.geo`
files regenerate them, and each mesh's sha256 is in the results JSON. Two gmsh runs of the r 35.5 mm level-1 `.geo` gave
the same sha256 (761d328d6c9815d5...) (verified, ran).

## OR-11. Rotor field of D09 at the copper plane

### Model as built

`or11.py` writes the gmsh geometry and the GetDP problem from one `Case` record. The geometry is one pole pair
2τ = 2πr/p (27.882 mm at r 35.5 mm, p 8) with the layers of the specification: outer air 5, iron 5, magnet 2, air 1,
board 1 (copper 0.07, core 0.86, copper 0.07), air 1, magnet 2, iron 5, outer air 5 (mm). The magnets are α_p·τ wide
(11.15 mm at r 35.5 mm), centred on each pole, magnetised along y with B_r 1.33 T and µ_r 1.05, and both rotors at one x
carry the same direction. The iron is linear with µ_r 1000. A_z = 0 holds on the two outer edges, and a GetDP `Link`
constraint makes A_z periodic between x = 0 and x = 2τ (corner nodes excluded). The formulation is H = ν(B - B_r) with
first-order nodal A_z, as in the U-S6 smoke test.

The b_n come from A_z sampled at 4096 points on the line. Because B_y = -∂A/∂x and A_z is continuous, b_n = -k_n·s_n,
where s_n is the sine coefficient of A_z about the pole centre. The same coefficients from sampled B_y agree within
0.002 % (column "B-sampled b1" below; verified, ran). The peak is Σ b_n for n 1 to 13 at the pole centre, as the
specification asks.

### Mesh convergence (r 35.5 mm, copper L1)

| level | h mm | nodes | b1 T | change | peak T | change |
|---|---|---|---|---|---|---|
| 0 | 0.25 | 8556 | 0.845530 | - | 0.737021 | - |
| 1 | 0.125 | 32645 | 0.845525 | -0.001 % | 0.737042 | +0.003 % |
| 2 | 0.0625 | 127063 | 0.845525 | -0.000 % | 0.737052 | +0.001 % |

h applies in the magnets, gaps and board. It grows to 2h at the iron outer faces and to 4h at the outer edges. Level 0
has 4 elements across each 1 mm gap. The copper rows are structured, with 4, 8 and 16 elements across 0.07 mm. The last
halving changes b1 and the peak by at most 0.001 %, against the 0.5 % criterion (verified, ran). The periodic mismatch of
A_z between the two cut edges is at most 1.5e-12 of max |A_z|. gmsh prints "Gmsh must be compiled with ANN support for
finding closest nodes" for each periodic curve (in `solver_log.txt`). The node pairs still match. The scikit-fem
reader asserts each right-edge node lies 2τ from a left-edge node at the same y within 1e-12 m (verified, ran).

### Cross-check with scikit-fem

`solve_skfem` reads GetDP's level-1 mesh (r 35.5 mm) and assembles my own P1 form, ∫ν∇A·∇v = ∫νB_r·curl v, with the
periodic pairs merged by a node map and A = 0 eliminated. It has 32373 unknowns, the same count GetDP prints. It agrees
with GetDP within 1.4e-13 on b1 and the peak on all three lines (verified, ran). This checks the problem file (signs,
magnet source, periodic link), not the discretisation error. The convergence table checks that.

### Why the FEA is 0.07 % below embodic

EQ-05 assumes infinitely permeable iron and a magnet layer of uniform µ_r. Runs at level 2 separate the two:

| run | b1 T | change from base | b1 vs embodic | peak vs embodic |
|---|---|---|---|---|
| base (iron 1000, air between magnets) | 0.845525 | - | -0.07 % | -0.18 % |
| iron µ_r 10000 | 0.846781 | +0.149 % | +0.08 % | -0.01 % |
| iron µ_r 1e5 | 0.846907 | +0.163 % | +0.09 % | +0.00 % |
| µ_r 1.05 between the magnets | 0.844726 | -0.094 % | -0.16 % | -0.18 % |
| both idealisations (EQ-05's model) | 0.846108 | +0.069 % | -0.002 % | -0.002 % |
| outer air 10 mm | 0.845525 | +0.000 % | -0.07 % | -0.18 % |
| magnet µ_r 1.03 (embodic also at 1.03) | 0.852487 | +0.823 % | -0.11 % | -0.18 % |
| magnet µ_r 1.10 (embodic also at 1.10) | 0.828622 | -1.999 % | +0.02 % | -0.18 % |

With EQ-05's own idealisations the FEA reproduces embodic to 0.002 % on b1 and on the peak (verified, ran). The
residual of the base case is therefore the finite iron permeability (about -0.16 %) and the air between the magnets
(about +0.09 %), both modelling differences that EQ-05 declares (inferred from the runs). The larger deficit at
r 44 mm fits the iron term, since the yoke path grows with τ (inferred). The magnet µ_r (G23) moves both models
together, so the comparison does not depend on it.

The specification asks that iron µ_r 10000 move b1 by less than 0.1 %, or that the change be reported. It moves b1 by
+0.149 %. That is above the 0.1 % line and 1/34 of the band, so it cannot change the verdict (verified, ran).

## OR-12. Eddy loss of one D09 trace

### Model as built

`or12.py` writes one rectangle 0.8 × 0.07 mm at the origin, width along x, inside a 24 mm square air box (30 × w). The
copper has σ = 1/1.7241e-8 S/m and µ_r 1. A_z = A_ext on the box edge, with A_ext = -B0·x for 12a (B_y = B0, normal to the
wide face) and A_ext = B0·y for 12b (B_x = B0, along the wide face), B0 = 0.846122 T. GetDP solves the complex
time-harmonic problem with J = -jωσA in the copper. The trace and the boundary data are odd about the centre, so A is
odd and the net current is zero with no scalar potential. The run prints |∫J|/∫|J| at 1e-7 to 2e-6 (verified, ran).
The loss per metre is ∫σω²|A|²/2 over the copper.

Skin depth at 266.67 Hz is 4.0468 mm, so w/δ = 0.198 and t/δ = 0.0173. At 3466.67 Hz (13 f_e) δ is 1.1224 mm,
w/δ = 0.713 and t/δ = 0.0624 (verified, computed in `or12.py`; embodic's `skin_depth_mm` prints the same δ).

### Mesh convergence and the meaning of the agreement

| case | copper h mm (levels 0, 1, 2) | loss W/m at level 2 | last change | FEA / embodic - 1 |
|---|---|---|---|---|
| 12a B_z, 266.67 Hz | 0.0175, 0.00875, 0.004375 | 1.740834e-01 | -0.000 % | -5.5e-07 |
| 12b B_t, 266.67 Hz | same | 1.332826e-03 | -0.000 % | -3.0e-09 |
| 12a B_z, 3466.67 Hz | same | 2.941737e+01 | -0.000 % | -9.3e-05 |
| 12b B_t, 3466.67 Hz | same | 2.252476e-01 | -0.000 % | -5.0e-07 |

Level 0 already has 4 elements across 0.07 mm and h far below δ/10. The 2 % criterion is met with no measurable change.
EQ-12 is exact in the low-frequency limit of this case. There J = jωσB0·x across the width, which integrates to
σω²B0²w³t/24 for any rectangle, and A_ext is linear, which P1 elements hold exactly. The FEA can differ from EQ-12 only
through the eddy currents' own field. At 266.67 Hz that field is 0.1 % of B0 at the trace centre, in quadrature
(imaginary B_y -8.6e-4 T for 12a), so the loss changes in second order, by 5.5e-7 (verified, ran; the second-order
reading is inferred). OR-12 as specified therefore tests the w, t ≪ δ condition of EQ-12. The uniform-field condition is
built into the case.
