# U-V16: do the spiral coils of D08 short? (user report, 0.0.3 on Windows)

Date 2026-10-20, branch `unit/U-V16` on main 0ad66be. `src/` there equals 0.0.3 (main 2fb2ec6): `git diff --stat
2fb2ec6 0ad66be -- src` is empty. Container Linux x86-64, CPython 3.11.17, numpy 2.4.6, PySide6 6.11.2,
`QT_QPA_PLATFORM=offscreen`, `PYTHONPATH=src`, one process. Nothing here ran on Windows (standing order 8). The user's
screenshot was read, not copied.

## Verdict: (b)

The copper is clear on every layer. The view misleads, because it draws L1 and L2 opaque in one colour per phase, one
on top of the other. No pair of copper shapes on one layer comes closer than the rule unless the design joins it. That
holds for D08 and for the other four packaged examples (`verified`, below). The product DRC misses nothing on these
boards. One section 7 exemption is wider than it needs to be: rule 5's end-point clause. It hides no violation on the
five examples, but a mutant shows that it can (DEF-UV16-01). The geometry view has two defects: no layer cue
(DEF-UV16-02), and round pads drawn as squares (DEF-UV16-03).

6; rule 2, 3. All are designed joints by the definition above except one, the neutral-ring tap (rule 2 tap, via 61 on

rule.

## V3-10's shared assumption

V3-10 found the D08 violation set equal to the product's, and it ran M1's sweep under `contract_exemptions`
(`m1/drc_universe.py`), Agent 4's own model of the same section 7 rules. It therefore inherits whatever section 7
exempts. Rule 5's end-point clause is read the same way there (`_tees`, l.236) as in `items.py` `_junctions`, so V3-10
could not see the pairs of DEF-UV16-01. This sweep uses no section 7 rule.
