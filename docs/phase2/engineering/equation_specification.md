# Equation specification v1.0 (Phase 2, 2026-10-04)

This document is the engineering contract for the embodic calculation engine. Agent 3 implements it. Agent 4 verifies it.
It supersedes `docs/phase1/engineering/equation_specification_draft.md`. The machine-readable copy is
`equation_registry.json` (generated by `checks/build_registry.py`). Frozen reference cases are in `oracle_cases.json`
(generated by `checks/build_oracle_cases.py`). The spiral generator algorithm is in `spiral_generator_spec.md`.
`checks/check_consistency.py` proves that this file, the registry and the oracle file use the same IDs and verdicts.

## How to read an entry

Each entry EQ-nn gives the formula, the sources (EV ids of `docs/phase1/evidence/evidence_register.md` with page), the
variables and units, the validity range, the limitations, a reference case with numbers, a tolerance with its basis, the
gate verdict, the dominant assumed inputs, the validity checks (EC), the topologies it applies to, and the test IDs.

Gate verdicts (unchanged from Phase 1, PROJECT_BRIEF §5):

- `reuse`: port the Xcoil code as is. Golden regression against `/home/claude/serpentine/src/engine.js` at function level,
  relative 1e-9, same inputs, Xcoil-compatible constants injected (ρ₂₀ 1.724e-8, copper density 8.96 g/cm³).
- `reuse with change`: the unchanged core passes the golden regression. The change is checked by closed-form and oracle
  tests only.
- `replace`: new code from this specification. Closed-form and oracle tests only. No bug-for-bug port.
- `cannot verify yet`: port with golden regression (so the estimate equals Xcoil's) and ship the result as a labelled
  estimate under the status rule D-007. EQ-14 is the one exception. embodic implements its form (a) instead of porting
  Xcoil, so a closed-form case (CF-12) replaces the golden regression (revision 2026-10-16 (U-E12), D-049 d).

Test IDs: `EQT-nn-GR` golden regression, `EQT-nn-CFxx` closed-form case CF-xx of `oracle_cases.json`, `EQT-nn-O1`/`-O2`
literature oracle, `EQT-nn-EC` validity check, `EQT-nn-UTk` unit test of a rule stated here. Agent 6 maps them into the
Phase 2 test plan.
For an `EQT-nn-CFxx` test the case CF-xx (its inputs, expected values and tolerances) governs over the entry's Phase 1
reference and tolerance texts, which stay as the Phase 1 record (revision 2026-10-13 (U-E10), D-046 d; registry note
"v1.0 rev. U-E10"). The texts that differ are the EQ-06 tolerance and the EQ-12 and EQ-13 reference cases.

Status labels follow standing order 2. `verified` means read in the cited source or reproduced by a script in `checks/`.
No number in this document is a measurement. Units are SI unless stated. Geometry is in mm where marked.

Common symbols: p pole pairs (2p poles); Q coils per layer; m phases; r radius; z axial distance from the magnet face;
θ mechanical angle; θ_e = pθ; ω_m mechanical speed; f_e = pω_m/2π; B_r remanence; µ_r recoil permeability; l_m magnet
thickness; α_p pole-arc ratio; g air gap per side; t_s stator thickness; G magnet face to symmetry or iron plane;
w trace width; t copper thickness; s clearance; w_d = w + s; N turns per coil per layer.

## Equations

### EQ-01 Pole pitch, coil pitch, electrical angle, phase offset

- Formula: τ_p(r) = πr/p; θ_p = π/p; θ_cp = 2π/Q; θ_e = pθ. Serpentine phase offset θ_shift = 2τ/m for m = 3 and τ/2 for
  m = 2, with τ = π/p (engine.js `derive` line 184).
- Sources: D08 eq. 3.2 p.31 (EV-03). Coil pitch and phase offset by geometry (`inferred`).
- Variables: p, Q [1]; r [mm]; τ_p [mm]; θ_p, θ_cp [rad].
- Validity: equally spaced coils. Limitation: none.
- Reference: 2p = 16, Q = 12 → θ_p 22.5°, θ_cp 30° = 240° electrical (arithmetic).
- Tolerance: exact. Gate: `reuse` (`derive`, `deriveWave`, `slotAngle`). Status: verified.
- Dominant assumptions: none. Applies to: spiral, serpentine, wave. Tests: EQT-01-GR, EQT-01-UT1.

### EQ-02 Turn limit of a spiral coil

- Formula: loop rule of `spiral_generator_spec.md` step G3. Spiral turn t exists when its outer arc exists
  (d_t < R_out,t sin(π/Q)) and its inner end (the arc at R_in,t from the right side d_t to the left side d_t+1, or the
  apex of those two lines) lies inside its outer arc, and its right side is at least `min_side_length` (default 2w).
  Cross-checks: D08 eq. 3.24 N < ½((R_o0 − R_i0)/w_d + 1) and printed eq. 3.25 and 3.26 (information only).
- Sources: D08 eq. 3.5 p.33, eq. 3.24 to 3.26 p.43 (EV-02, EV-06); loop geometry eq. 3.28 to 3.29 p.44 (EV-07).
- Variables: R_o0, R_i0 centre-line radii [mm]; w, s, gap [mm]; Q [1].
- Validity: one layer, sides parallel to the sector edges or radial, arc or straight ends.
- Limitations: printed eq. 3.25 and 3.26 mis-split trapezoidal and triangular loops (Phase 1 `checks/eq02_eq03_reference.py`).
- Reference (CF-10, CF-11, run by `checks/spiral_reference.py`): D08 → 3 turns (trapezoid, triangle, triangle), radial
  bound 6.007; default 12/16 → 11 turns (8 trapezoids + 3 triangles in spiral form). Eye-limited counts come from EQ-25.
  Concentric test mode (Phase 1 loop criterion, unchanged): D08 3, 12/16 11, 18/16 8. With `min_side_length` = 2w the
  generator gives 18/16 → 7 (the 8th right side is 0.607 mm < 1.0 mm).
- Tolerance: exact counts. Gate: `replace` (Xcoil `sectorFeasible`, `maxSectorTurns`, `maxSectorTurnsFor` have no
  triangular turns and are not ported). Status: inferred.
- Dominant assumptions: w, s, coil gap, via pad. Applies to: spiral. Tests: EQT-02-CF10, EQT-02-CF11, EQT-02-UT1.

### EQ-03 Track length (generated path; concentric closed form as cross-check)

- Formula: generated length L = Σ primLength over copper primitives (lines: chord; arcs: r|Δa|). Cross-check (D08
  eq. 3.28 to 3.36 corrected): loop i, d_i = (i + ½)w_d, φ = asin(d/R), β = θ_cp/2 − φ, L_out = 2R_out β_out,
  L_in = 2R_in β_in, L_s = d/tan φ_out − d/tan φ_in, L_i = L_out + L_in + 2L_s.
- Sources: D08 p.44 to 45 (EV-07); D09 Table 1 p.3 (phase trace lengths).
- Variables: lengths [mm].
- Validity: closed form = concentric loops with sharp corners; generated = any primitive list.
- Limitations: the closed form over-estimates a true spiral by +4 % to +8 % for many turns and by +21 % to +32 % for
  2 to 3 turns with triangular inner turns (Phase 1 `checks/eq03_spiral_vs_loops.py`; CF-10 +25.45 %, CF-11 +5.16 %).
- Reference: CF-04 arc 30 mm × 90° = 47.1238898 mm; CF-10 D08 body 141.2781 mm vs closed form 177.2331 mm; CF-11 default
  body 396.3481 mm vs closed form 416.8085 mm.
- Tolerance: generated vs reference model relative 1e-6 (same rules) or ±1 % (fillet or lead conventions differ). The
  closed form is never an acceptance oracle on its own.
- Gate: `reuse` (`primLength`, `primsLength`, `discretize`). Status: inferred.
- Dominant assumptions: w, s, loop model. Applies to: spiral, serpentine, wave.
  Tests: EQT-03-GR, EQT-03-CF04, EQT-03-CF10, EQT-03-CF11.

### EQ-05 Air-gap field (2-D harmonic model per radius)

- Formula (odd n): K_n = (4B_r/(nπ)) sin(nπα_p/2); u = np/r;
  B_z,n = K_n cosh(u(G − z))/[cosh(uG) + µ_r coth(u l_m) sinh(uG)], B_t,n = K_n sinh(u(G − z))/[same].
  G = (t_s + 2g)/2 double rotor; t_s + 2g single rotor with yoke; G → ∞ single rotor without yoke.
- Sources: D08 eq. 3.1 p.31 (EV-03); D09 eq. 1 p.4 (EV-13); closed form is my derivation, algebraically equal to the
  engine's exponential form (CF-01 reproduces both within 7.2e-11).
- Variables: z, l_m, g, t_s, G [mm]; B_r [T]; µ_r [1].
- Validity: linear magnets, unsaturated infinitely permeable back iron, parallel magnetisation, 2-D per radius.
- Limitations: no radial edge leakage (EC-05); back-iron saturation (D08 p.112); µ_r unsourced (G23, 1.05 `assumption`,
  range 1.03 to 1.10).
- Reference: CF-01 B_z1 = 1.162077823 T (1-D limit, B_r 1.3, µ_r 1.05, l_m 3, α_p 0.85, G 1.1). Phase 1: D09 rotor
  0.738 T vs D09 Fig. 7 FEA about 0.72 T (figure reading, `inferred`).
- Tolerance: 1e-9 vs CF-01; ±5 % on B₁ at mid-radius vs 3-D FEA (D09 p.4 reports < 1 % for its comparable model; plus
  µ_r and B_r(T) uncertainty).
- EC-05 radial edge leakage (graded, DEF-18 and DEF-23). e_edge = Σ w·D_e exp(−d/(c_e G))/Σ w, w = |B_z1 r Δr| over the
  EMF segments in the magnet span, d = distance to the nearer magnet end, D_e = 0.47, c_e = 0.9. Rule: e_edge ≤ 10 % → no
  badge cap, one-sided add-on "model may be high by at least e_edge"; e_edge > 10 % → badge `unresolved`.
  Labels (DEF-23):
  (a) The calibration quantity is |B| "at the middle of the magnet" from D09 Fig. 7 (caption p.4, axial position not
  stated). EC-05 uses it as a proxy for B_z at the copper. Near the radial ends |B| also holds a radial component, so the
  B_z deficit is at least as large. e_edge is therefore probably a lower bound (`inferred`).
  (b) The calibration is `inferred` (one case). Its transfer to other rotors (other l_m, α_p, pole pitch, block or
  T-arrangement magnets) is an `assumption`.
  (c) The 10 % threshold is an `assumption`, a design choice. The calibration case sits at 5.6 to 5.8 %, so 10 % allows
  about 1.7 times extrapolation. It is not derived from the ±8 % O1 band.
  (d) D09 is both the calibration source and oracle O2, so O2 cannot validate EC-05. O1 (D08) is the only independent
  check. It depends on the G10 gap reading (e_edge 4.21 % at G 1.4 mm, 5.11 % at G 1.7 mm, Agent 4 v12).
  Registry typed fields (requirements.md section 6, D-017): `threshold` 0.10, `metric_bound` lower_bound,
  `calibration_status` inferred, `transfer_status` assumption, `threshold_status` assumption, `independent_oracles` OR-01,
  `dependent_oracles` OR-07 and OR-08. The prose reasoning stays in `basis`, `transfer_basis` and `threshold_basis`.
  Consequences (Phase 1 `checks/edge_zone_d09.js`): default 12/16 5.3 %, O1 4.2 %, O2 5.8 %. None is capped.
- Gate: `reuse with change` (`fieldHarmonic`, `fieldSetup`). Changes: α_p(r) (EQ-04), B_r(T), configurable odd harmonic
  set (default 1 to 13), EC-05, one rotor type for field, inductance and inertia. Status: inferred.
- Dominant assumptions: B_r, µ_r, l_m, g, back iron, α_p. Applies to: spiral, serpentine, wave.
  Tests: EQT-05-GR, EQT-05-CF01, EQT-05-CF03, EQT-05-EC, EQT-05-O1, EQT-05-O2.

### EQ-08 Phase assignment and winding factor

- Formula: exact star of slots for concentrated coils. a_k = 12(kp mod Q) in units of 360°/(12Q);
  belt = ⌊(a_k + Q)/(2Q)⌋ mod 6 with half-open belts [c − 30°, c + 30°); belts A+, −C, B+, −A, C+, −B. Balanced iff the
  signed angle sets of B and C equal A's shifted by 4Q and 8Q units. Feasibility check Q mod 3 = 0, (Q/t) mod 3 = 0,
  t = gcd(Q, p), Q ≠ 2p. k_d,n = |Σ s_k e^{jnα_k}|/N_A; k_p,n = |sin(npσ/2)|; spiral average
  k_p,avg = (1/N) Σ_t |sin(npσ_t/2)|. Wave: integer belts `beltPhase`, `beltSign`.
- Sources: D15 eq. 6 p.7 (EV-59, per-turn average); D04 eq. 1 p.5 (EV-26); D07 p.3 (EV-58); D12 eq. 1 p.3 (EV-56).
  Feasibility rule: `assumption: standard result` (G24), always confirmed by the explicit balance check.
- Variables: Q, p, k [1]; α [rad].
- Validity: identical, equally spaced coils.
- Limitations: Xcoil `starOfSlots` floors floating angles; coils on a belt edge (12/10 has 6 of 12) fall either way.
  12/14, 24/14, 24/22, 24/26 come out unbalanced in Xcoil (C6; `checks/engine_probe.js` prints ok = false).
- Reference (CF-09): 12/10 "AabBCcaABbcC" = D08 Fig. 3.7 p.36 (`verified (reproduced)`); 12/14 "ACcbBAacCBba";
  12/16 "ACBACBACBACB"; 18/16 "AabBbcCcaAabBbcCca"; all balanced. k_d1: 12/10 0.965926, 12/16 1.0, 18/16 0.959795.
- Tolerance: exact patterns; k_d, k_p 1e-9.
- Gate: `replace` (`starOfSlots`, `balancedSectorList` not ported; wave `beltPhase`, `beltSign`, `slotAngle` golden).
  Status: inferred.
- Dominant assumptions: none for k_d, k_p. Applies to: spiral, wave. Tests: EQT-08-CF09, EQT-08-GR, EQT-08-UT1.
- U-M2c questions (revision 2026-10-05 (U-E3), both `inferred` from the star-of-slots arithmetic above; no source in the
  evidence register; registry status unchanged).
  (a) One phase per layer pair (option M4). All Q coils of a pair must be co-phasal up to sign, so neighbouring coils
  differ by p·θ_cp = 2πp/Q, which must be a multiple of π: 2p/Q is an integer k. k_p1 = |sin(kπ/2)| is 1 for odd k
  and 0 for even k. So the pair gives EMF and is self-consistent when 2p/Q is odd (Q = 2p, 2p/3, ...), not only when
  Q = 2p. Balance between the three phases then comes from the pair rotation (θ_cp/3 electrical steps), not from G7.
  (b) Parallel paths a. Each path must carry the same EMF phasor. The winding repeats t = gcd(Q, p) times, so a must
  divide t; a ≤ t is not enough (t = 4, a = 3 cannot split four equal sub-windings into three equal paths). When Q/t is
  even, alternate sub-windings are equal and opposite, and a may also divide 2t. A citable textbook entry is a gap.

  R_phase = ρ_T L_tot / (w_tr t_tr). The equations have no term for leads, vias, inter-coil connections or the star

- Gate: `reuse with change` (`rotorInertiaEstimate`). Changes: cite densities; prefer the user's inertia (Xcoil does).
  Status: assumption. Dominant assumptions: densities, yoke geometry. Applies to: spiral, serpentine, wave.
  Tests: EQT-28-GR.

### EQ-29 Inter-layer capacitance (upper bound)

- Formula: C_i = ε₀ ε_r min(A_Cu,i, A_Cu,i+1)/t_diel,i.
- Sources: parallel-plate capacitor (standard); engine.js `stackCapacitance` 1180 to 1188; ε_r table unsourced.
- Variables: A [m²]; t [m]; ε_r [1]; C [F]. Validity: t ≪ copper extent.
- Limitations: full overlap, no fringing → upper bound.
- Reference: A 1000 mm², t 0.2 mm, ε_r 4.5 → 1.99215e-10 F (arithmetic, ε₀ 8.854e-12). Revision 2026-10-08 (U-E5): with the registry's CODATA 2022 ε₀ (EV-85) the same case gives 1.99219e-10 F; the code still uses 8.854e-12 until Agent 3 changes it.
- Tolerance: 1e-4 relative (ε₀ digits). Gate: `reuse with change` (`stackCapacitance`). Changes: source ε_r, label
  "upper bound". Status: assumption. Dominant assumptions: ε_r, dielectric thickness.
  Applies to: spiral, serpentine, wave. Tests: EQT-29-GR.

### EQ-30 DRC clearance computation and acceptance

- Formula: clearance(a, b) = min distance between discretised centre-line segments − (w_a + w_b)/2 (pads: distance to the
  pad outline). Violation iff clearance < rule − ε, ε ≤ 1e-6 mm (D-006). The arc discretisation error is bounded by the
  sagitta tolerance and subtracted, so the computed clearance is never larger than the exact one.
- Sources: decision D-006. Xcoil uses tol = 0.004 mm at engine.js lines 757, 1929, 2147, 2429 (`checks/engine_probe.js`).
- Variables: w_a, w_b [mm]; rule [mm]; ε [mm].
- Validity: line and arc primitives with round caps.
- Limitations: Xcoil's slack hides intrusions up to 4 µm.
- Reference: `checks/engine_probe.js` Xcoil default serpentine trace clearance 0.199011 mm with rule 0.2 mm: Xcoil ok,
  embodic violation (DEF-P2-02).
- Tolerance: DRC values 1e-9 vs Xcoil; pass/fail agreement only outside [rule − 0.004, rule).
- Gate: `reuse with change` (`runDrc`, `drcLayer`, `drcPadVsLayer`, `drcObjects`, `drcLayerObjects`, `drcInterconnect`,
  `padsClearance`, `padSegClearance`, `segSegDist`, `ptSegDist`, `canonicalSegments`, `makeGrid`, `gridQuery`).
  Changes: remove the slack; conservative sagitta. Status: inferred.
- Dominant assumptions: fabricator clearance rule. Applies to: spiral, serpentine, wave. Tests: EQT-30-GR, EQT-30-UT1.
